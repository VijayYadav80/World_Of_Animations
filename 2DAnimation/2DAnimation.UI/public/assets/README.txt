FORMAT / USE
------------
- SVG files are scalable vector assets.
- Character parts are in characters/<character>/parts/.
- Character rig files are in characters/<character>/rig.json.
- Background SVGs are in backgrounds/.
- Open SVG files in a browser, Inkscape, Figma, or import them into compatible
  animation software.
- Rig JSON files are asset metadata; they are not a complete animation project.

The bundle preserves the files from the provided source ZIPs. It does not claim
that the assets are a fully rigged animation scene in every animation app.
