# Phase 3 — Animation engine

Copy the folders from this zip over the repo (same relative paths; it includes updated Phase 2 files). No new npm packages.

## Wire into the editor (2 lines)
In the component that hosts the right-hand panel: add `ActionPanelComponent` (`src/app/timeline/action-panel.component.ts`) to `imports`
and put `<app-action-panel />` under `<app-properties-panel />`.

## Try it
Select Raju -> click **Demo: Walk -> Idle -> Sit -> Talk -> Get Up -> Walk**. Raju walks, sits, talks (mouth moves), gets up and walks on.
Or add actions one by one. Drag the slider to scrub: the pose is recomputed from the time, so scrubbing is exact.

## What is implemented
- `core/animation/animation-engine.ts` — pure, deterministic: `evaluatePose(rig, timeline, t)`, `evaluatePosition`, cross-fade between actions (220 ms),
  posture rules (`canAppend`: no Walk while sitting, no Sit while sitting, ...), additive clips (Wave/Talk/Point keep the current stand/sit posture).
- 10 clips as data in `rig.json`: idle, stand, walk (loop), run (loop), sit, get-up, jump, wave, talk (loop), point. Generated by `tools/gen_clips.py`.
- Feet stay on the ground: hip height is solved with forward kinematics per frame (run/jump include intentional flight).
- Walk/Run add position keyframes (`groundSpeed` px/s x scale) so Raju travels without foot sliding. Dragging on the stage edits the keyframe at the playhead.
- `PlaybackService` (play, pause, seek, restart, ms clock). Stage evaluates the engine every frame.

## Verified offline (this sandbox)
- `node --experimental-strip-types tools/test-engine.mjs` — 18 checks pass: determinism when scrubbing, posture rules, seated pose, additive talk while seated,
  get-up ends standing, ground contact (walk 1.3 px, sit/get-up/idle < 0.3 px).
- `tools/render-clips.mjs` renders every clip frame-by-frame; checked by eye (walk, run, sit, get-up, jump, wave, point, talk look correct and joints stay connected).
- Engine + models pass `tsc --strict`.
- NOT verified: Angular compile of the new components and the PixiJS runtime (no browser/npm here). Paste any error and I will fix it.

## Known limits
- Talk = open/closed mouth states, no phoneme-accurate lip-sync. Point = forward only (flip to point the other way).
- Sitting is on an invisible seat (hip ~100 px above ground); a chair prop comes later.
- Properties panel X/Y show the static position; for a character with position keyframes they do not follow the animated position yet.
- Timeline is a list + slider for now; the graphical timeline with drag/trim is Phase 4.
